# FlowLife Productivity Suite

A client-side productivity application featuring local user account authentication, isolated storage per account, and 8 productivity modules.

## Updated Features
- **Brand Identity:** Renamed to **FlowLife** with tiny logo integration (`assets/icon.png`) in the header.
- **Removed Callout Banner:** The top callout box on the home page has been removed for a clean dashboard view.
- **Local Account Engine:** Sign Up and Sign In functionality with per-user data isolation.
- **8 Core Modules:** Dashboard, Calendar, Schedule, Habits, Budget, Tasks, Notes, and Analytics.
